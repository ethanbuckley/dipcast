How good is the forecast?

Every forecast SwimSignal issues is logged and scored later against what the overflows actually did. This page updates itself. It also shows the offline tests the model was built on.

Reading the numbers

The Brier score is the mean squared difference between a probability and what happened (0 or 1). Lower is better; 0 is perfect. Climatology means always forecasting the long-run average. Skill is how far below climatology's Brier score the forecast gets, as a fraction: 0 is no better than the average, 1 is perfect. AUC is how well the forecast ranks spill days above dry days: 0.5 is random, 1 is perfect. A reliability table checks that days forecast at 30% happen about 30% of the time.

Model and verification code: open source under MIT. Live scores use the water companies' published overflow status; an overflow counts as spilling on a day if any published event overlaps it. An overflow-day counts as "no spill" only if that overflow was observed with a known status at least six times that day and once the next day; a poll gap, an offline monitor or a dead feed is a missing observation, not a dry day. The forecast scored for each day is the one available at 08:00 local time on the day it was issued.
