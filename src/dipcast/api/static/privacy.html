Privacy notice

What dipcast collects, and what it does not. Last updated 12 September 2026.

No accounts, no cookies, no tracking

dipcast has no user accounts and sets no cookies. There is no analytics script and no third-party tracking. Map tiles are loaded from OpenStreetMap's servers, which see your IP address as any website's image server would; their privacy policy applies to that.

What the server records

When you click the map the server receives the coordinates you clicked and your IP address, like any web request. dipcast keeps a log of forecasts issued (the coordinates, the time and the forecast values) so that it can score its own accuracy afterwards and publish the results on the verification page. This log does not contain your IP address, any identifier, or anything about you. Standard web-server access logs, which do contain IP addresses, are kept briefly for operating the service and are not analysed for anything else.

Shareable links

A forecast's address contains the coordinates you clicked. Anyone you send the link to can see the location. Do not share a link to your home.

If alerts are added

A planned feature would let you save a spot and receive an email when the forecast for it changes. If that is added, this notice will be updated first. Emails would be stored only to send those alerts, never shared or sold, and you would be able to delete your address at any time.
